# MFU Canteen Web App

The **MFU Canteen Web Application** is a university-level food ordering and management system built with **Spring Boot**, **Thymeleaf**, **MYSQL** and **Javascript**. It allows students to browse menus, place orders, and view their order history, while canteen owner can manage items, and track orders.

---

## 📌 Project Overview

The goal of the MFU Canteen project is to digitalize and streamline the food ordering experience at Mae Fah Luang University. It provides a user-friendly interface for:

- Students and staff to **browse menus**, **order food**, and **check order status**
- Canteen staff/admins to **manage menu items**, **track real-time orders**, and **update statuses**
- A secure login system with **role-based access**

## 💡 Key Features

### 🧑‍💻 User Side (Students & Staff)
- Register/Login system
- View available menu items with images, prices, and descriptions
- Add items to cart and place orders
- View **order history** and **order status updates**

### 🧑‍🍳 Shop Owner Side (Canteen Staff)
- Login with owner credentials
- Add, edit, delete food menu items
- View incoming orders in real-time
- Update order status (e.g., Preparing, Ready, Completed)
